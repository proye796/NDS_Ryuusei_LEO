## 추가 기능

필드에서 **START를 누른 채 SELECT**(또는 둘을 동시에)를 누르면 부가 기능 창이 열립니다. SELECT만 누르면 원래대로 트랜서를 바꿉니다. 대화·이동 연출 중에는 열리지 않으며, 받은 것은 저장해야 남습니다. 게임 안에서 직접 모을 수 있는 것은 넣지 않았습니다.

| | 웨이브 배틀 카드 | 처음에는 꺼져 있습니다. 켜면 아래 키 설명이 나옵니다. |

웨이브 배틀 카드를 켜 두면, 전투의 커스텀 화면에서 카드를 고르는 중에 아래 키로 웨이브 배틀 카드를 스캔합니다(완구 카드를 스캔한 것과 같음).

| 버튼 | 웨이브 배틀 카드 | 바뀌는 카드 |
|---|---|---|
| Ｘ | 기가마인 | 무속성 카드 |
| Ｙ | 옥스 파이어 SP | 불 속성 카드 |
| 셀렉트 | 페가수스 매직 GX | 물 속성 카드 |

- 커스텀 화면의 카드 가운데 속성이 맞는 첫 카드가 바뀝니다. 한 턴에 한 번, 같은 웨이브 배틀 카드는 전투마다 한 번만 쓸 수 있고, 바뀐 카드는 그 전투에서만 쓰입니다.
- 통신 대전과 튜토리얼 전투에서는 동작하지 않습니다.
- 브라더 추가에는 빈 브라더 칸이 필요합니다(4~6번 칸, 브라더 6명 등록이 가능해진 뒤에는 1~3번 칸도).
