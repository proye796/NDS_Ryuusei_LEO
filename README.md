## 추가 기능

받은 것은 저장해야 남습니다. 게임 안에서 직접 모을 수 있는 것은 넣지 않았습니다. 쓰기 전에 세이브 파일을 따로 복사해 두세요.

### 버전 선택

타이틀 화면(「PRESS START」가 깜박일 때나 「처음부터 / 이어서」 메뉴)에서 **십자 버튼 좌우**로 페가수스·레오·드래곤을 고릅니다. 고른 버전의 로고로 타이틀이 다시 뜨고, 「이어서」에는 그 버전의 세이브가 나옵니다. 세이브 파일 하나에 세 버전의 세이브가 따로 들어가며, 다음에 켜면 마지막에 고른 버전으로 뜹니다.

### 통신 메뉴

트랜서의 통신 메뉴에서 받습니다. 화면과 등록·저장은 원작 그대로이고, 상대(배포기·다른 버전 세이브·『우리들의 태양 DS』)의 대답만 게임이 대신합니다.

| 고르는 곳 | 상대 | 내용 |
|---|---|---|
| 게스트 → 호스트 목록 | 배포 브라더 | 원래 배포로만 맺을 수 있던 레전드 마스터 신이 브라더가 됩니다. 링크 어빌리티는 HP+와 기가 클래스+1입니다. |
| | 배포 카드 | 기가 클래스 카드 「안드로메다」를 정품으로 받습니다. 세이브당 한 번입니다. |
| 호스트로 기다리기 | 다른 버전 세이브 | 약 3초 뒤 「게스트에게서 통신 신청이 왔어」와 함께 그 세이브의 플레이어 이름과 버전이 나옵니다. 「통신 시작」 → 「VERSUS / TRADE」(아래). |
| | 『우리들의 태양 DS』 | 다른 버전 세이브 다음에 신청합니다. 「통신 시작」이면 원작 크로스 오버로 장고(Lv100)가 브라더가 되고, 「태양의 열쇠」 4개·「ＦＭ팔찌」·「유성파워」도 받습니다. 최대 HP +220, 차지 +1, 브라더 룰렛 「우태ＤＳ포스」, 우주 구역의 붉은 미스터리 웨이브(태양의 열쇠로 열기)와 특수 초록 미스터리 웨이브가 생깁니다. 이미 브라더면 갱신만 합니다. |

- 신청을 「그만둔다」로 넘기면 약 3초 뒤 다음 상대가 신청합니다(다른 버전 세이브 → 『우리들의 태양 DS』). 다른 DS를 기다릴 때도 「그만둔다」로 넘기면 됩니다. 진짜 게스트·호스트와의 통신은 그대로입니다.
- **VERSUS(브라더)**: 대전 없이 바로 원작의 브라더 신청으로 갑니다. 서로의 비밀을 확인하고(내 비밀이 없으면 키보드로 정함) 칸을 고르면 「(이름)하고 브라더가 됐어!」 → 저장. 상대 버전에서도 같은 과정을 하면 서로 브라더가 됩니다. 이미 브라더인 버전과 다시 하면 갱신됩니다.
- **TRADE(카드 교환)**: 게임기 한 대로는 두 카드를 동시에 고를 수 없어 두 번에 나눕니다.
  1. B 버전에서 호스트로 기다리기 → A 버전의 신청 → TRADE → 내줄 카드를 고릅니다. 「친구가 트레이드를 취소한 것 같아」가 나오며, 이때 B의 카드는 아직 그대로입니다.
  2. A 버전에서 호스트로 기다리기 → B 버전의 신청 → TRADE → 내 카드를 고르면 1에서 B가 고른 카드가 상대 카드로 나오고, 원작대로 교환·저장됩니다.
  3. B를 다음에 불러오면 B 쪽 교환이 반영됩니다. B를 저장하면 확정됩니다.
  - 1에서 「없음」을 고르면 A의 카드를 B에게 선물로만 줍니다. 레전드 포스 카드는 버전 사이에 트레이드할 수 없습니다.

### 부가 기능 창

필드에서 **START를 누른 채 SELECT**(또는 둘을 동시에)를 누르면 부가 기능 창이 열립니다. SELECT만 누르면 원래대로 트랜서를 바꿉니다. 대화·이동 연출 중에는 열리지 않습니다.

| 메뉴 | 항목 | 내용 |
|---|---|---|
| 카드・아이템 | 암호 보상 | 게임 안에 단서가 있는 16개를 뺀 암호 44개의 보상(배틀 카드 38장, 아이템 6개)을 한 번에 받습니다. 한 번만 받을 수 있습니다. |
| | 우태 ＤＳ 카드 | 태양총 V1·V2·V3, 암흑검 V1·V2·V3, 어슐러·토베·오트프리트·리자 V3, 모두 10장 가운데 가진 적 없는 카드만 1장씩 받습니다. 한 번만 받을 수 있습니다. |
| | 다른 버전 카드 | 고른 버전이 아닌 두 버전의 전용 카드 16장(메가 6장, 기가 10장) 가운데 가진 적 없는 카드만 1장씩 받습니다. |
| 웨이브 스캐너 | 레벨·버전 | 웨이브 스캐너 완구 역할입니다. 레벨(ＬＶ１~９９)과 버전(페가수스·레오·드래곤)을 맞춘 뒤 트랜서의 워록 화면에서 Ｘ를 누르면 데이터를 보내고, 원작처럼 받아 저장합니다. 저장한 데이터가 적용 중이면 모든 전투를 그 버전의 스타 포스 형태로 시작합니다. 맞춘 값은 버전마다 따로이고, 전원을 끄면 사라집니다. |
| 어시스트 | 버스터 | 록 버스터(보통 샷·차지 샷) 공격력 100~500%. 배틀 카드는 그대로입니다. |
| | 대미지 | 받는 대미지 경감 0~100%. 경직·상태 이상은 그대로 일어납니다. |
| | 제니 | 배틀 후 받는 제니 100~500%. 결과 화면 숫자는 원래 금액이고 실제로 받는 돈만 늘어납니다. |
| | ＨＰ 회복 | 켜면 이기거나 도망친 배틀 뒤 HP가 최대로 회복됩니다. |
| | 도주 | 켜면 도주가 반드시 성공합니다(도망칠 수 없는 배틀은 제외). |
| | 인카운터 | 무작위 배틀 빈도: 하지 않음 / 저(약 절반) / 중(원래) / 고(약 2배) / 최고(움직이자마자). 이야기의 배틀은 그대로입니다. |
| 설정 | 에그제 연동 | 켜면 GBA 슬롯에 『록맨 에그제』를 꽂은 것과 같아져 연동 이벤트가 열립니다. 코다마 타운 개집의 전뇌 → 전망대 동상의 전뇌(재밍거와 전투, 「미지 데이터」) → 개집의 전뇌에서 록맨.EXE에게 「Ｅ블래스터」를 받습니다. 한 번만 일어납니다. |
| | 스타 포스 선택 | 처음에는 꺼져 있습니다. 켜면 스타 포스 카드를 고를 때 브라더가 없어도 세 형태 중에서 고를 수 있습니다(아래). |
| | 웨이브 배틀 카드 | 처음에는 꺼져 있습니다. 켜면 아래 키 설명이 나옵니다. |

어시스트 설정은 세이브에 남고 버전별 세이브마다 따로이며, 처음에는 모두 원래 값입니다. 버스터·대미지·제니·도주는 통신 대전과 튜토리얼 전투에서는 원래대로입니다.

웨이브 배틀 카드를 켜 두면, 전투의 커스텀 화면에서 카드를 고르는 중에 아래 키로 웨이브 배틀 카드를 스캔합니다(완구 카드를 스캔한 것과 같음).

| 버튼 | 웨이브 배틀 카드 | 바뀌는 카드 |
|---|---|---|
| Ｘ | 기가마인 | 무속성 카드 |
| Ｙ | 옥스 파이어 SP | 불 속성 카드 |
| 셀렉트 | 페가수스 매직 GX | 물 속성 카드 |

- 커스텀 화면의 카드 가운데 속성이 맞는 첫 카드가 바뀝니다. 한 턴에 한 번, 같은 웨이브 배틀 카드는 전투마다 한 번만 쓸 수 있고, 바뀐 카드는 그 전투에서만 쓰입니다.
- 통신 대전과 튜토리얼 전투에서는 동작하지 않습니다.

스타 포스 선택을 켜 두면, 전투의 커스텀 화면에서 스타 포스 카드를 골랐을 때 아이스 페가수스·파이어 레오·그린 드래곤을 고르는 창이 뜹니다. 원래는 다른 버전의 브라더가 있어야 나오는 게임의 창이고, 고른 형태로 변신합니다. 통신 대전과 튜토리얼 전투에서는 원래대로 브라더에 따라 정해집니다.
